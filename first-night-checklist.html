First Night Astronomy Checklist

Use this checklist to avoid common setup errors and leave your first session with useful results instead of frustration.

Check weather first Setup guide

Checklist

1. Before sunset

  • Charge everything: telescope, phone, accessories.
  • Check app and firmware updates while still indoors.
  • Pack dew control, warm layers, and spare power.
  • Pick one realistic target only.

2. Location and conditions

  • Confirm cloud and seeing on weather planning.
  • If target is faint, use dark sky guidance.
  • Avoid direct local lights if possible.
  • Set up on stable ground.

3. Setup and alignment

  • Level setup as well as you can.
  • Follow default alignment flow in the app.
  • Do not rush first connection and calibration steps.
  • Take a test frame before committing to a long capture.

4. Capture routine

  • Start with short runs and check star shape or lunar detail.
  • Change one setting at a time only.
  • If conditions worsen, pivot to a brighter target.
  • Save one original frame and one edited version.

5. End-of-session notes

  • What target did you attempt?
  • What condition blocked quality (cloud, dew, vibration, focus)?
  • What one change will you make next session?
  • What did you do well that you should repeat?

Red flag checklist

  • Trying too many targets in one night.
  • Updating firmware outside at the last minute.
  • Skipping weather checks and hoping for clear breaks.
  • Changing many settings without logging changes.
